# IE(I) - VIT Chennai

Official website for The Institution of Engineers (India) - VIT Chennai Student Chapter.

## About

The Institution of Engineers (India) – Student Chapter is a community dedicated to empowering engineering students through innovation, technical growth, and industry exposure.

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone https://github.com/Punyamittal/ie-i-.git

# Step 2: Navigate to the project directory
cd ie-i-/IE-I--main

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```

The development server will start at `http://127.0.0.1:5173`

## Project Structure

- `/src/pages` - Page components
- `/src/components` - Reusable components
- `/src/components/ui` - UI component library
- `/public` - Static assets

## Building for Production

```sh
# Build the project
npm run build

# Preview the production build locally
npm run preview
```

The production build will be in the `dist` directory.
